# Idle RPG — Master Item Candidate Checklist

> **Status:** Expandable candidate register; initial seed list only. Nothing here is automatically approved, implemented, or established as Merzkava canon.
> **Scope:** Standalone Offline Game / Idle RPG only. This catalog is independent from Convo's prompt, inventory presentation limits, and GM-facing item conventions.
> **Authority:** Official Merzkava Universe → reviewed World Archive package → approved Offline Game content pack. Original game additions must remain explicitly labelled and save/content-pack scoped.

## 1. Rules for this checklist

- [ ] Keep this as the single expandable master register for Idle RPG. Add entries in-place; do not create competing lists by screen or activity.
- [ ] Each individual item receives its own checkbox and stable ID when promoted into the structured catalog.
- [ ] A checked box means reviewed and approved for the Idle RPG catalog, not merely imagined or illustrated.
- [ ] Provenance labels: **CANON** = explicitly established by an official Universe source; **CANON_ADAPTATION** = game-facing representation derived from canon without claiming the exact item is canon; **IN_GAME_ORIGINAL** = new content authored only for Offline Game.
- [ ] Every CANON entry cites exact Universe path, source commit, and supporting passage. Every adaptation cites its source dossier and explains the adaptation. Every original entry is marked non-canon and assigned to a game content-pack version.
- [ ] Plausibility does not prove an item exists in a particular region, shop, dungeon, profession, or encounter. Availability, recipe, drop, price, effects, and rarity each need separate approval.
- [ ] Keep uncertain names provisional. Do not invent official artifact names, Spirit Beast drops, Arcanistry formulas, materials, or mechanics and present them as canon.
- [ ] Buildings, roads, terrain, farms, mines, workshops, resource nodes, and other placeable world objects belong to the isometric map catalog, not carried inventory.
- [ ] Currency remains in the official wallet system. Do not duplicate Xuan denominations as crafting loot or turn Zun Jade / Ancient Zun into crafting materials.
- [ ] Spirit Realm, Martial Soul, Spirit Ring absorption status, Arcanist Grade, Arcanist Focus, HP, Energy, and progression values remain character/status data unless a real physical object is separately established.
- [ ] This register is designed to grow to thousands of individually reviewed entries. Keep distinct species, cuts, grades, variants, and functional objects separate when they need different identity, artwork, or gameplay behavior.

## 2. Structured record template

| Field | Required meaning |
|---|---|
| Item ID | Stable ID, never reused after retirement |
| Display name | Approved player-facing name |
| Category / subcategory | One primary category and optional tags |
| Provenance | CANON / CANON_ADAPTATION / IN_GAME_ORIGINAL |
| Source | Exact Universe path + commit, Archive dossier, or game-content authoring record |
| Availability | Region, biome, season, vendor, activity, quest, or encounter gates |
| Item state | Identified, unidentified, damaged, reserved, equipped, consumed, stored, etc. |
| Stack / quantity | Stack rules and units |
| Condition | Durability, freshness, spoilage, purity, quality, only where supported |
| Gameplay use | Approved uses, recipes, trade, quest, equipment, or collection roles |
| Artwork | Unique item illustration asset and category-frame family |
| Review | Owner, date, decision, and evidence |

## 4. Explicitly separate from item inventory
- [ ] Buildings, houses, shops, farms, mines, workshops, academies, facilities, roads, bridges, wells, docks, boats used as map assets, terrain, map decorations, large trees, and placeable resource nodes remain world/map objects with their own footprint, state, ownership, and interaction logic.
- [ ] A harvested unit of wood, ore, fish, crop, or stone is an item; the tree, ore deposit, fishing spot, crop plot, or stone outcrop is a world object/resource node.
- [ ] A completed workshop is a map/building asset; a carried hammer, measuring gauge, component, or blueprint is an item.
- [ ] Currency is wallet data using official denominations; it is not duplicated into generic inventory stacks.
- [ ] Spirit Realm, Martial Soul, Arcanist Grade, Arcanist Focus, HP, Energy, skills, learned knowledge, and progression counters are character data, not ordinary item cards.
