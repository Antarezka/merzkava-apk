Audit lanjutan menemukan skrip emulator smoke-test memiliki blok pemeriksaan launch yang terduplikasi dan sintaks shell rusak. Karena itu hasil emulator dari skrip lama tidak boleh dianggap sebagai bukti launch yang valid. Skrip diperbaiki menjadi satu alur tegas: install package → resolve launcher → ActivityManager melaporkan `Status: ok` → window aplikasi benar-benar foreground → PID proses terdeteksi → tidak ada fatal crash aplikasi → capture dua frame splash Kitty.

Workflow validation juga menjalankan `bash -n scripts/emulator-smoke-test.sh` sebelum unit tests.

Format versi APK yang ditetapkan:
- Bentuk: `v.1.01.BUILD-HASH`.
- `1`: major line aplikasi.
- `01`: feature-rich Android line.
- `BUILD`: nomor urut run workflow; dipakai juga sebagai Android `versionCode` agar tetap numerik dan meningkat.
- `HASH`: tiga karakter pertama commit yang benar-benar dibangun, sebagai identitas source.
- Contoh pola: `v.1.01.246-abc` (contoh format, bukan klaim hasil build).

Workflow wajib menyetel `versionName` dari pola tersebut dan memeriksa nilai `versionName` serta `versionCode` langsung dari manifest APK sebelum artifact diunggah. Versi final hanya ditetapkan setelah run build yang sesuai selesai.
