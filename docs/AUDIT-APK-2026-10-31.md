## 2. Fitur yang sudah ada pada source feature-rich

Dikonfirmasi dari source `a866623` (tree sama dengan `613b959`, kecuali skrip smoke-test):

- Tampilan: Archive Light / Archive Night (Dark Mode), preferensi tema.
- Audio: Sound On/Off, opening chime, suara judul, efek antarmuka.
- Splash Kitty: Anime.js, layer PNG terpisah untuk body, head, tail, dan shadow; animasi masuk/idle, partikel, glow/reflection, wordmark.
- Halaman: Home, Gameplay, Inventory, Map, Journal, Settings, serta tampilan Character.
- Karakter: registry pemain dari pinned `players.md`, refresh registry, profil Markdown lengkap, inventory dan wallet awal.
- Gameplay: chat per karakter, world time, GM engine, pemuatan konteks canon.
- Save: checkpoint, resume, validasi profil checkpoint.
- State: parser profil GM dan reconciliation untuk mencegah perubahan status yang tidak sah.
- Inventory/keuangan: inventory, wallet, wallet ledger, gameplay log, notifikasi perubahan, proposal bubble item/mata uang.
- Ledger Log (Anime.js): `src/ui/ledger-log.ts` memakai `animate` dari `animejs` untuk notifikasi bubble. Mencakup kategori wallet, inventory, HP, satiety, body, equipment, cultivation, dan other; bubble menampilkan perubahan serta nilai before/after, label canon, dan detail. Bubble melayang/bergoyang, auto-dismiss, dapat di-tap untuk efek crystalline/snowflake pop, dibatasi maksimal empat notifikasi aktif, dan menghormati `prefers-reduced-motion`. Riwayat transaksi disimpan per karakter di localStorage (maksimal 500 entri), disiarkan melalui event `merzkava:ledger-change`, lalu ditampilkan kronologis di Inventory. Proposal item/mata uang dari GM hanya menampilkan bubble bertanda belum disahkan; tidak langsung menulis ledger atau mengubah state.
- Canon: loader, router aktivitas canon, context assembler, cache dokumen dan snapshot.
- AI: Supabase authentication dan AI Gateway.
- Android Floating Mode: Floating Control, izin overlay/notifikasi/battery, Kitty bubble, strip, mini-window, foreground service.
- SQLite schema 5 dengan tabel `characters`, `character_stats`, `inventory_items`, `wallet_ledger`, `gameplay_logs`, `canon_documents`, `canon_documents_snapshot`, dan `gameplay_sessions`.

Catatan: halaman Map dan Journal tersedia sebagai halaman navigasi; audit source ini tidak membuktikan bahwa keduanya sudah memiliki fitur peta/jurnal interaktif penuh.

## 8. Detail verifikasi Ledger Log Anime.js

Pemeriksaan source langsung pada `src/ui/ledger-log.ts`, `src/ui/floating-ledger.css`, dan pemanggilnya di `src/main.ts` memastikan:

- Library: `animejs`, diimpor melalui `import { animate } from "animejs"`.
- `recordLedgerChange()` menyimpan entri per karakter, memunculkan bubble, dan mengirim event `merzkava:ledger-change`.
- `getLedgerLog()` membaca kembali riwayat tersimpan; entri divalidasi dan diurutkan berdasarkan waktu.
- `showLedgerProposalBubble()` secara eksplisit hanya menampilkan proposal sementara dan tidak menulis ledger/mengubah state.
- Animasi bubble memakai drift melayang (`translateX`, `translateY`, `rotate`, `scale`), sedangkan dismiss memakai scale/opacity/blur dan partikel snowflake yang dianimasikan terpisah.
- Klik bubble menutupnya; auto-dismiss berjalan setelah sekitar 5,2 detik; stack dibatasi empat bubble.
- CSS menyediakan tampilan glassy bubble, tone positif/negatif/netral, serta panel riwayat ledger di Inventory.

Status: **fitur ada pada source feature-rich dan wajib dipertahankan**. Keberadaan source dan lolosnya web build tidak dengan sendirinya membuktikan animasi sudah diuji pada perangkat Android; verifikasi runtime tetap menunggu emulator.
