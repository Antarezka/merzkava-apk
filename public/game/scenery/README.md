# Offline Game — Scenery Assets

This directory stores landscape backgrounds and reusable environmental art for the Offline Game.

## Rules
- Keep source artwork separate from runtime-generated lighting and weather effects.
- Master scenery targets 1920×768 (2.5:1); preserve a clean, unobstructed composition.
- Preferred formats: WebP for runtime backgrounds; PNG for transparency or lossless source assets.
- Do not bake time-of-day, rain, fog, snow, UI, labels, or characters into master scenery unless a specific asset explicitly requires them.
- Use canon-verified settlement and landmark names only. Unknown locations remain unassigned until checked against Merzkava Universe.
- The game may adapt canon material, but asset filenames do not make new lore canon.

See [ASSET_MANIFEST.md](ASSET_MANIFEST.md) for the complete checklist.
