# Complete Academy Exterior Map

This folder is reserved for the **fully assembled academy exterior map**: one continuous, large-scale isometric scene with the complete campus layout and all buildings and environment elements integrated.

## What belongs here

- The complete campus composition, not isolated building or ground assets.
- All academy buildings placed in their final map positions.
- Connected roads, courtyards, gardens, ponds, bridges, waterways, training grounds, and other exterior features.
- Full-resolution editable/source map and its optimized in-game export.
- Optional preview images showing the entire map.

## Suggested filenames

- `academy-exterior-full-source.png` or the native editable project format.
- `academy-exterior-full-preview.png`
- `academy-exterior-full.webp` for the optimized runtime export.

Keep reusable ground tiles in `../ground/` and individual buildings, trees, and props in `../objects/`. This folder is specifically for the **complete integrated map**.

The campus layout is a visual design interpretation of the Merzkava Universe World Archive. Do not treat unconfirmed building names, exact campus geography, or decorative details as new canon.
